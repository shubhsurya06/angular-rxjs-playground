# Angular RxJS Playground

An Angular project demonstrating practical usage of core RxJS operators and async patterns.  
Includes real-world examples of `forkJoin`, `mergeMap`, `switchMap`, `concatMap`, and `exhaustMap`.  
Built to showcase strong understanding of reactive programming and stream management in Angular.

---

## 🚀 Purpose

This repository is created as a learning and portfolio project to:
- Practice RxJS operators commonly used in Angular applications
- Understand differences between mapping operators
- Explore concurrency, cancellation, and sequencing in observables
- Demonstrate reactive programming skills in a real-world context

---

## 🧠 RxJS Concepts Covered

- `forkJoin`
- `mergeMap`
- `switchMap`
- `concatMap`
- `exhaustMap`
- Observable streams
- HTTP request handling
- Async data flow management
